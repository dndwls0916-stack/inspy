1. 빠른 시작 (Windows)

  1. 압축 풀기 — 받은 ai-council-windows.zip을 우클릭 → 모두 압축 풀기. 원하는 폴더(예: 바탕화면)에 풉니다. 폴더 안에는 ai-council-win-x64.exe와 이 설명서가 있습니다. (압축을 풀지 않고 zip 안에서 바로 실행하지 마세요.)
  2. 실행하기 — ai-council-win-x64.exe를 더블클릭합니다. 검은 콘솔 창이 뜨고 잠시 뒤 브라우저가 자동으로 열립니다. 안 열리면 브라우저 주소창에 http://localhost:3000을 입력하세요.
  3. 파란 경고가 뜨면 — "Windows의 PC 보호" 창이 나오면 추가 정보 → 실행을 누르세요. (서명하지 않은 개인 프로그램이라 나오는 정상 경고입니다.)
  4. 처음 한 번 설정 — 처음 실행하면 실행파일 옆에 .env 설정 파일이 자동으로 만들어집니다. 아래 2번에서 AI를 연결하세요. (CLI 로그인 방식이면 이 파일은 건드리지 않아도 됩니다.)
  5. 질문하기 — 아래 입력칸에 질문을 쓰고 회의 시작(Ctrl+Enter)을 누릅니다.
  6. 끝내기 — 콘솔 창을 닫으면 프로그램이 종료됩니다.

A. CLI 로그인 방식

각 AI의 공식 명령줄 프로그램(CLI)에 한 번 로그인해 두면, 이 프로그램이 그것을 대신 실행해 줍니다. API 키는 필요 없습니다. 쓸 AI만 준비하면 됩니다.

  1. Node.js 설치 — codex와 gemini는 npm으로 설치합니다. nodejs.org에서 LTS 버전을 설치하세요. (이 프로그램 자체는 Node.js가 필요 없지만, 이 CLI들은 필요합니다.) 설치 후에는 새 명령 프롬프트(cmd) 창을 여세요.
  2. CLI 설치 — 명령 프롬프트나 PowerShell에 쓸 AI의 줄만 입력합니다. 
    npm install -g @anthropic-ai/claude-code     (Claude → 유비)
npm install -g @openai/codex                (GPT → 관우)
npm install -g @google/gemini-cli           (Gemini → 장비, 아래 '중요' 참고)

    (Claude 모델 별칭은 sonnet, opus, haiku를 쓸 수 있습니다(실제 동작 확인). Claude Code는 공식 설치 프로그램으로도 설치할 수 있습니다. 각 공식 문서의 안내가 바뀌었다면 그쪽을 따르세요.)

  3. 한 번씩 직접 실행해 로그인 — 명령 프롬프트에서 claude, codex, gemini를 각각 입력하면 브라우저 로그인 안내가 나옵니다. 로그인(구독 계정)을 마치고, 처음 나오는 "이 폴더를 신뢰하시겠습니까?" 같은 질문까지 대화형으로 끝낸 뒤 종료하세요. 이 과정을 건너뛰면 회의 중에 CLI가 질문에서 멈춰 시간 초과가 날 수 있습니다.
  4. 설치 확인 — claude --version, codex --version, gemini --version이 버전을 출력하면 됩니다.
  5. 이 프로그램 실행 — exe를 (새로) 더블클릭합니다. 콘솔에 CLI 사용 가능: GPT, Gemini, Claude처럼 인식한 AI가 표시되어야 합니다. 키가 하나도 없으면 자동으로 CLI 방식으로 시작합니다. (설치한 뒤에는 PATH가 반영되도록 반드시 새로 실행하세요.)
  6. 화면에서 확인 — 왼쪽 실행 방식이 CLI 로그인인지 보고, 참가자 카드에 경고가 없는지 확인합니다. 모델 칸은 비워 두면 각 CLI의 기본 모델을 씁니다.
CLI 방식 요령
  • 회의 1번 = AI 호출 여러 번입니다(3명×2라운드면 8번). 구독 한도가 빨리 줄 수 있으니 처음엔 라운드 1로 시험하세요.
  • 한 번 호출에 10~60초 걸립니다. 3분 안에 응답이 없으면 그 카드에 시간 초과 오류가 표시되고 회의는 계속됩니다.
  • 먼저 터미널에서 claude -p "안녕" 같은 명령이 직접 되는지 확인하면, 문제가 CLI 쪽인지 이 프로그램 쪽인지 바로 구분됩니다.
Windows 안내npm으로 설치한 codex·gemini는 Windows에서 .cmd 파일입니다. 이 프로그램은 이를 자동으로 찾아 실행하도록 만들어 두었지만, 제작 환경에 Windows가 없어 실제 Windows에서는 아직 검증하지 못했습니다. 안 되면 콘솔의 오류 메시지를 알려 주세요. 실행파일이 PATH에 없다면 .env에 GEMINI_BIN=C:\경로\gemini.cmd처럼 직접 적을 수 있습니다(CLAUDE_BIN, CODEX_BIN도 같음). 모델 이름에는 영문·숫자·. _ : / -만 쓸 수 있습니다.
중요 — Gemini CLI의 "Sign in with Google"은 막혔습니다 개인 구글 계정으로 gemini에 로그인하면 This client is no longer supported for Gemini Code Assist for individuals 오류가 나는 경우가 있습니다. Google 쪽 정책 변경이라 이 프로그램이나 PC 설정의 문제가 아닙니다. Gemini만 API 키로 쓰면 됩니다. (아래 C. 혼합 방식)

C. 혼합 방식 — Claude·GPT는 CLI, Gemini는 API 키

AI마다 API 키가 있으면 API로, 없으면 CLI로 자동 선택합니다. 구독으로 쓰는 Claude·GPT와 무료 API 키로 쓰는 Gemini를 한 회의에 함께 쓸 수 있습니다.

  1. Gemini API 키 발급(무료 사용량 있음) — aistudio.google.com에 구글 계정으로 로그인 → Get API key → 키 만들기. 키는 AIza...로 시작합니다. 무료 사용량에는 분당 요청 제한이 있어, 가끔 429 오류가 날 수 있습니다.
  2. .env에 키 한 줄 넣기 — 실행파일 옆 .env를 메모장으로 열어 아래처럼 쓰고 저장합니다. Claude·GPT 키는 비워 두세요(비어 있어야 CLI가 쓰입니다). 
    GEMINI_API_KEY=AIzaxxxxxxxxxxxx
  3. .env의 MODE=api 줄 지우기 — 이전 버전이 만든 .env에 MODE=api가 있으면 자동 선택이 막힙니다. 그 줄을 삭제하세요(또는 MODE=mixed로 바꾸세요). 새로 만들어지는 .env에는 이 줄이 없습니다.
  4. 프로그램 다시 실행 — 콘솔에 기본 실행 방식: MIXED가 보이면 됩니다. 화면 왼쪽 실행 방식에서 혼합이 선택되어 있는지 확인하세요.
  5. 확인 — 회의를 시작하면 군의 장면의 각 인물 이름 옆에 실제 사용한 경로가 Claude · CLI, Gemini · API처럼 표시됩니다.
참고이 경우 gemini CLI는 설치하지 않아도 됩니다. 어떤 AI에 API 키를 넣으면 그 AI는 (CLI가 있어도) API로 호출됩니다. 그 AI를 CLI로 쓰고 싶으면 키를 비우세요.

B. API 키 방식

  1. 키 발급받기 (각 사이트에서 로그인 후 "API Keys" 메뉴. 결제 수단이나 크레딧이 필요할 수 있습니다)
    AI발급 페이지.env 에 쓰는 이름
    GPT (관우)platform.openai.com → API keysOPENAI_API_KEY
    Gemini (장비)aistudio.google.com → Get API keyGEMINI_API_KEY
    Claude (유비)console.anthropic.com → API KeysANTHROPIC_API_KEY
    참고ChatGPT·Gemini·Claude 구독(월정액)과 API 키는 별개입니다. API는 사용량만큼 따로 과금됩니다.
  2. .env 파일 열기 — 실행파일과 같은 폴더의 .env를 메모장으로 엽니다. (우클릭 → 연결 프로그램 → 메모장. 파일이 안 보이면 폴더 보기 옵션에서 "숨긴 항목"과 "파일 확장명"을 켜세요.)
  3. 키 붙여넣기 — = 뒤에 따옴표·공백 없이 붙여 넣고 저장합니다. 쓸 AI만 채우면 됩니다. 
    OPENAI_API_KEY=sk-xxxxxxxxxxxx
GEMINI_API_KEY=AIzaxxxxxxxxxxxx
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxx
  4. 다시 실행 — 콘솔 창을 닫고 exe를 다시 더블클릭합니다. 콘솔에 API 사용 가능: GPT, Claude처럼 인식한 AI가 표시되면 성공입니다. (.env를 고치면 항상 다시 실행해야 반영됩니다.)
키는 비밀번호와 같습니다키를 채팅·메일·스크린샷으로 남에게 보내지 마세요. .env 파일이 든 폴더를 통째로 공유하지 마세요. 노출됐다면 해당 사이트에서 키를 삭제하고 새로 발급받으세요.

파일 첨부

질문 입력칸 위의 📎 첨부를 누르거나 파일을 화면에 끌어다 놓으면 파일 내용을 참고 자료로 함께 보냅니다. 모든 AI가 같은 자료를 읽고 토론합니다. 답변에서는 파일 이름을 밝히며 인용하도록 요청합니다.

읽을 수 있는 것텍스트·마크다운(.txt .md), 표·데이터(.csv .tsv .json .xml), 코드(.py .js .ts .java .c .go 등), 로그·자막(.log .srt .vtt), PDF, Word(.docx)
아직 안 되는 것이미지(사진·스크린샷), 한글(.hwp), 압축 파일, 글자가 없는 PDF(스캔한 이미지 PDF). 엑셀·파워포인트는 아래 📁 폴더로 읽을 수 있습니다.
한도파일 30개까지, 글자 합계 80,000자까지(넘치면 앞부분만 들어가며 "일부만" 표시). 한 파일은 20MB 이하. PDF는 앞 150쪽까지 읽습니다.
한글 파일메모장 등으로 저장한 CP949(ANSI) 한글 파일도 자동으로 인식합니다.
  • 첨부는 화면에서 제거(×)하거나 "새 회의 시작"을 누를 때까지 유지됩니다. 이어서 질문할 때도 같은 자료가 계속 들어갑니다.
  • 글자 추출은 내 PC의 브라우저에서 이루어지고, 추출된 글자만 질문과 함께 서버를 거쳐 AI 회사로 전송됩니다. 파일 원본이나 PDF 라이브러리가 외부로 나가지는 않지만, 파일 내용은 선택한 AI 회사의 서버로 전송됩니다. 개인정보·기밀 문서는 올리지 마세요.
  • 첨부 안에 "이전 지시를 무시하라" 같은 문장이 있어도 AI에게는 참고 자료로만 전달하며 따르지 않도록 지시합니다. 다만 AI의 판단이므로 100% 보장은 아닙니다. 출처를 알 수 없는 파일은 신중히 올리세요.
첨부가 크면 사용량이 크게 늘어납니다첨부 내용은 모든 AI의 모든 라운드 호출마다 다시 들어갑니다(합의 판정 호출은 제외). 예를 들어 30,000자 문서를 3명이 2라운드 토론하면 그 문서가 약 8번 읽힙니다. API 요금이나 구독 한도, 무료 Gemini 키의 분당 제한(429)에 걸리기 쉬우니 필요한 부분만 올리세요.

폴더 지정: 문서를 읽히고 결과물 저장

읽는 것텍스트·코드·CSV·JSON 등 + Word(.docx), 엑셀(.xlsx, 시트별 표), 파워포인트(.pptx, 슬라이드별 글자와 발표자 노트)
안 읽는 것PDF(폴더 읽기에서는 아직 안 됨 — 📎 첨부로는 가능), 한글(.hwp), 옛 형식(.xls .ppt .doc → 새 형식으로 저장하세요), 이미지. 엑셀의 차트·수식 결과가 아닌 수식 자체, 그림 속 글자도 못 읽습니다.
자동 제외.env, 키·인증서 파일(.pem .key id_rsa), 이름에 secret/password/credential 이 들어간 파일, 숨김 파일, node_modules 등은 목록에서 빼고 내용도 읽지 않습니다.
한도파일 하나당 앞 30,000자, 첨부 합계 80,000자(📎와 공통). 용량이 넘치면 뒤쪽 파일은 체크가 풀려 있습니다.

결과물 저장: 회의가 끝나면 최종 결론 아래에 💾 결과물로 저장 줄이 나옵니다. 파일 이름과 형식(.md · .docx · .xlsx · .pptx · .html · .txt · .csv)을 고르고 저장하면 지정한 폴더 안의 결과물 폴더에 새 파일로 만들어집니다.

  • 저장은 항상 새 파일입니다. 같은 이름이 있으면 -2, -3을 붙이며 기존 파일은 덮어쓰거나 지우지 않습니다. 폴더 안의 다른 곳에는 쓰지 않습니다.
  • .docx는 결론의 제목·목록을 간단히 옮긴 워드 문서이고, .xlsx는 결론 안의 표(| 로 된 표, 쉼표/탭 구분)를 시트로 옮깁니다(표가 없으면 한 줄에 한 칸). .pptx는 결론의 제목줄(#, ##)마다 슬라이드 한 장, 그 아래 줄은 글머리로 만든 기본 서식의 흰 배경 슬라이드입니다(한 장에 7줄이 넘으면 "(계속)" 장으로 넘어가고, 최대 60장). 그림·차트·디자인 템플릿은 없으니 파워포인트에서 다듬어 쓰세요.
  • AI가 폴더의 파일을 직접 고치거나 실행하지는 않습니다. AI는 글자로 읽고 글자로 답하며, 파일은 이 프로그램이 위 규칙대로만 저장합니다.
  • 읽은 폴더의 내용은 📎 첨부와 마찬가지로 선택한 AI 회사의 서버로 전송됩니다. 체크한 파일만 보내지니, 개인정보·기밀 파일은 체크를 풀어 주세요.

직업 역할과 생각 깊이

참가자마다 직업 역할과 생각 깊이를 고를 수 있습니다. 같은 질문도 변호사·투자자·비판자처럼 서로 다른 전문가 관점에서 따져 보게 됩니다. (삼국지 모드는 AI 한 종류에 한 자리씩일 때만 쓸 수 있어, 같은 AI를 더 앉히면 자동으로 꺼집니다. 기본은 꺼져 있고, 필요하면 위쪽 체크박스로 켭니다. 역할과 함께 쓸 수도 있습니다.)

역할변호사 · 투자자 · 회계사/세무사 · 의사 · 개발자 · 보안 전문가 · 마케터 · 제품 기획자 · 데이터 분석가 · 인사/노무 전문가 · 창업가 · 비판자(악마의 변호인) · 연구자/교수 · 고객 대변인. 각 역할은 그 직업의 관점과 반드시 점검할 항목을 지침으로 받습니다. 말투가 아니라 "무엇을 따지는가"가 달라집니다.
팀 구성"법률·계약 검토", "투자 판단", "제품·서비스 기획", "창업·사업", "개발 리뷰", "건강·생활" 중 하나를 고르면 체크된 참가자에게 순서대로 역할 세 개가 한 번에 배정됩니다. 개별로 바꿔도 됩니다.
생각 깊이자동 / 낮음 / 보통 / 높음. AI가 답하기 전에 얼마나 깊이 따져 볼지입니다. 높을수록 답이 느리고 사용량이 늘어납니다. 자동은 각 서비스의 기본값입니다. 참가자마다 따로 고를 수 있습니다.
  • 생각 깊이는 서비스별로 이렇게 전달됩니다: GPT는 reasoning_effort, Claude는 effort(API) / --effort(CLI), Gemini는 사고 예산·수준(API), Codex CLI는 model_reasoning_effort. Gemini CLI는 이 설정이 없어 무시됩니다.
  • 모든 모델이 이 설정을 받는 것은 아닙니다. 받지 않는 모델이면 자동으로 설정 없이 다시 호출하고, 발언 머리의 "깊이 높음" 표시에 줄이 그어져(미적용) 나타납니다. 오류로 멈추지는 않습니다.
  • 결론 정리와 합의 판정에는 역할이 붙지 않아 중립을 유지하고, 결론 문서의 "의견이 갈린 점"에는 누가 어떤 직업 관점이었는지가 나옵니다.
전문가 자문을 대신하지 않습니다변호사·의사·세무사·투자자 역할은 해당 분야의 일반적인 관점으로 따져 보는 도구입니다. 법 조문·판례·세율·시세 같은 구체 사실은 AI가 틀릴 수 있어(역할 지침에서 지어내지 말라고 하지만 보장은 아닙니다), 계약·건강·세금·투자의 실제 결정은 반드시 전문가나 공식 자료로 확인하세요.

합의까지 토론

토론 라운드에서 "합의까지"를 고르면 정해진 횟수가 아니라 서로 같은 결론에 이를 때까지 토론합니다. "결론 날 때까지 (제한 없음)"은 라운드 상한 없이 합의될 때까지 계속합니다. 다만 끝없이 돌지 않도록 두 라운드 연속 진전이 없으면 평행선으로 보고 멈추며, 안전 상한은 30라운드입니다. 라운드가 길어지면 첫 라운드와 최근 2라운드만 원문으로 두고 중간 라운드는 판정 요약으로 줄여 AI에 보냅니다(요금과 속도 보호). 호출 수가 많으니 중단 버튼을 기억해 두세요.

  1. 1라운드: 각자 독립적으로 의견을 냅니다. (이때는 판정하지 않습니다)
  2. 2라운드부터: 서로의 의견을 읽고 반박하거나 입장을 바꾸며, 모두가 받아들일 공통 결론을 제안합니다. 매 라운드가 끝나면 사회자가 중립적으로 "핵심 결론이 실질적으로 같은가"를 판정합니다. 말만 바꾼 형식적인 "동의합니다"는 합의로 치지 않습니다.
  3. 합의가 아니면: "쟁점 남음" 카드에 남은 쟁점이 표시되고, 다음 라운드에서 그 쟁점에 집중해 토론합니다.
  4. 끝나는 조건: ① 합의가 되면 즉시 끝납니다. ② 정한 최대 라운드에 도달하면 끝납니다. ③ 두 라운드 연속 진전이 없으면(평행선) 끝납니다. 합의하지 못하고 끝나면 최종 결단이 합의된 척하지 않고 이견을 공정하게 요약합니다.
호출이 많이 늘어납니다3명이 최대 6라운드까지 가면 AI 호출이 약 25번(발언 18 + 판정 5 + 결론 1 + 제갈량 1)까지 늘 수 있고, 라운드당 몇 분이 걸릴 수 있습니다. API 방식은 요금이, CLI 방식은 구독 사용량이 더 듭니다. 처음에는 "합의까지(최대 4)"로 시험하고, 무료 Gemini 키는 분당 요청 제한(429)에 걸릴 수 있으니 참가자를 줄이는 것도 방법입니다. 판정도 AI의 판단이라 100% 정확하지는 않습니다.

회의는 이렇게 진행됩니다

  1. 1차 군의 — 각자 서로의 답을 보지 않고 의견을 냅니다.
  2. 2·3차 군의(선택) — 앞선 회의록을 읽고 동의·반박·수정된 입장을 말합니다.
  3. 최종 결단 — 결론 · 합의된 점 · 의견이 갈린 점 · 추천 다음 단계로 정리합니다.
  4. 제갈량의 한마디 — 한 줄 요약 · 군사의 책략 · 오늘의 첫 수 (삼국지 모드)

한 AI에서 오류가 나도 회의는 계속되고, 결론 담당이 실패하면 다른 AI가 대신 정리합니다. 오류는 해당 카드에 이유가 표시됩니다.

좋은 질문 요령배경·제약·원하는 결과를 함께 적으면 토론이 훨씬 날카로워집니다. 예) "팀 3명, 예산 적음, 3개월 안에 출시. 웹과 앱 중 무엇을 먼저?"

4. 비용과 한도

한 번의 회의에서 AI 호출 횟수는 대략 참가자 수 × 라운드 수 + 1(결론) + 1(제갈량)입니다. 예) 3명 × 2라운드 → 8회. 사회자와 제갈량은 결론을 쓴 같은 AI가 맡습니다. 요금을 아끼려면 라운드를 1로 줄이거나, 참가자를 줄이거나, 삼국지 모드를 끄세요(제갈량 호출 -1). API 방식은 각 사이트에서 월 사용 한도(Usage limit)를 걸어 두면 안전합니다. CLI 방식은 별도 요금은 없지만 같은 횟수만큼 구독의 사용량 한도를 소모합니다.

5. 문제 해결

브라우저가 자동으로 안 열려요

주소창에 http://localhost:3000을 직접 입력하세요. 콘솔 창에 적힌 주소와 같습니다.

"포트 3000이 이미 사용 중입니다"

프로그램이 이미 켜져 있거나 다른 프로그램이 3000번을 씁니다. 이미 켠 창을 닫고 다시 실행하거나, .env의 PORT=3000을 PORT=3001처럼 바꾸세요(이 경우 주소도 localhost:3001).

"사용 가능한 AI가 없습니다"

키도 CLI도 인식되지 않은 상태입니다. .env에 키를 넣고 프로그램을 껐다 켰는지 확인하세요. 키 앞뒤에 공백이나 따옴표가 없어야 합니다.

카드에 "HTTP 401" / "invalid api key"

키가 틀렸거나 삭제됐습니다. 새로 발급받아 .env를 고치고 재실행하세요.

"The 'gpt-5' model is not supported when using Codex with a ChatGPT account" (Codex CLI)

CLI 방식에서는 모델 드롭다운을 "자동"으로 두세요. 자동이면 Codex가 ChatGPT 계정에서 쓸 수 있는 기본 모델을 직접 고릅니다. 이름을 직접 적으면 계정이 지원하지 않는 모델일 수 있습니다.

"This model models/gemini-2.5-flash is no longer available to new users … use models/gemini-3.8-flash" (Gemini API)

자동 처리됩니다. 서비스가 대체 모델을 알려 주면 프로그램이 그 모델로 바꿔 다시 시도하고, 답변 카드에 실제로 쓴 모델(예: gemini-3.8-flash ← gemini-2.5-flash 대체)이 표시됩니다. 그래도 같은 오류가 반복되면 실행파일 옆 .env에서 GEMINI_MODEL= 줄을 지우세요(이전 버전이 만든 .env에는 모델이 고정되어 있을 수 있습니다). 아래는 이전 안내입니다.

(참고) "This model models/gemini-… is no longer available to new users" (Gemini API)

그 모델은 새 계정에서 더 이상 쓸 수 없습니다. 참가자 카드의 모델 드롭다운에서 지금 계정에서 쓸 수 있는 모델을 고르거나 "자동"을 고르세요(자동은 목록의 최신 주력 모델을 고릅니다). 오류 메시지가 추천한 모델 이름을 그대로 입력해도 됩니다.

카드에 "HTTP 404" / "model not found"

그 계정에서 쓸 수 없는 모델 이름입니다. 왼쪽 참가자 카드의 모델 칸을 계정에서 쓸 수 있는 모델로 바꾸세요. (모델 이름은 서비스가 자주 바꿉니다.)

Gemini: "HTTP 429 … Quota exceeded … generate_content_free_tier_requests, limit: 0, model: …"

"limit: 0"은 그 모델에는 무료 사용량이 아예 없다는 뜻입니다(요청이 많아서가 아닙니다). 신형이나 pro 계열 모델에서 흔합니다. 모델 드롭다운이 "자동"이면 프로그램이 무료로 쓸 가능성이 높은 모델(flash, flash-lite)을 먼저 시도하고, 한도 0이나 사용 불가 오류가 나면 다음 후보로 자동 전환합니다. 각 답변 카드 오른쪽 위에 실제로 쓴 모델 이름이 표시됩니다. 직접 고른 모델에서 이 오류가 나면 자동 전환하지 않으니 다른 모델을 고르거나 "자동"으로 바꾸세요. 신형 모델을 꼭 쓰려면 Google AI Studio에서 결제(유료 요금제)를 연결해야 합니다.

카드에 "HTTP 429" / quota

사용 한도나 크레딧이 소진됐거나 요청이 너무 빠릅니다. 결제·크레딧을 확인하고 잠시 뒤 다시 시도하세요.

"'xxx' 명령을 찾을 수 없습니다" / 참가자 카드에 "CLI 설치·로그인이 필요합니다"

해당 CLI가 설치되지 않았거나 PATH에 없습니다. ① 명령 프롬프트에서 claude --version(또는 codex/gemini)이 되는지 확인 ② 설치 직후라면 이 프로그램을 껐다가 새로 실행 ③ 그래도 안 되면 .env에 CLAUDE_BIN / CODEX_BIN / GEMINI_BIN으로 전체 경로를 적고 재실행하세요.

CLI 카드에 "종료 코드 1 …" 또는 시간 초과

카드에 표시된 마지막 메시지를 먼저 읽어 보세요. 대부분 ① 로그인이 안 됐거나 만료됨 → 해당 CLI를 직접 실행해 다시 로그인 ② 처음 실행 시 나오는 질문(폴더 신뢰, 약관 등)에서 멈춤 → 대화형으로 한 번 끝내기 ③ 구독 사용량 한도 소진 → 시간이 지난 뒤 재시도 ④ 인터넷 연결입니다. 터미널에서 claude -p "안녕"이 직접 되는지 확인하면 원인을 가를 수 있습니다.

Gemini 로그인: "This client is no longer supported for Gemini Code Assist for individuals"

개인 구글 계정 로그인이 중단된 것입니다. gemini CLI 대신 Gemini API 키를 쓰세요. 위 C. 혼합 방식을 따라 하면 됩니다.

"CLI 인자에 사용할 수 없는 문자가 있습니다"

모델 입력칸에 허용되지 않는 문자가 있습니다. 영문·숫자·. _ : / -만 쓰거나, 칸을 비워 CLI 기본 모델을 쓰세요.

백신이 실행파일을 막아요

서명되지 않은 단일 실행파일이라 일부 백신이 의심할 수 있습니다. 직접 받은 파일이 맞다면 예외로 등록하세요. 마음에 걸리면 아래 "개발자" 방법으로 소스에서 직접 실행할 수 있습니다.

① 지원 형식은 텍스트·코드·CSV·JSON·PDF·docx입니다. 엑셀은 CSV로 저장해서 올리세요. ② "글자가 없는 PDF"는 스캔한 이미지라서 글자를 읽을 수 없는 경우입니다. 글자를 복사할 수 있는 PDF를 쓰거나, 문서를 텍스트로 복사해 .txt로 저장해 올리세요. ③ 용량이 가득 차면 불필요한 첨부를 × 로 지우거나 필요한 부분만 잘라서 올리세요. ④ 한글이 깨져 보이는 일은 드물지만, 그럴 때는 메모장에서 "UTF-8"로 다시 저장해 올려 보세요.

6. Mac · Linux · 개발자

  • Linux: ai-council-linux-x64에 실행 권한을 주고 실행합니다. chmod +x ai-council-linux-x64 && ./ai-council-linux-x64
  • macOS: 서명 문제로 macOS에서 직접 빌드해야 합니다. GitHub 저장소의 Actions → Build executables → Run workflow를 실행하면 Windows·macOS·Linux용을 한 번에 받을 수 있습니다. 실행 시 막히면 우클릭 → 열기, 또는 터미널에서 xattr -d com.apple.quarantine ./파일명.
  • 소스에서 직접 실행(Node.js 18+ 설치 필요): 
    cp .env.example .env     # 키 입력 (Windows: copy .env.example .env)
npm start                # http://localhost:3000
npm run start:cli        # CLI 방식으로 시작
npm run demo             # 키 없이 화면만 확인 (가짜 응답)
npm test                 # 테스트
npm run build:exe        # 실행파일 빌드 (결과: dist/)
  • 캐릭터 바꾸기: lib/personas.js의 이름·칭호·색·말투를 고치면 됩니다.

7. 보안과 개인정보

  • 서버는 127.0.0.1(내 컴퓨터)에서만 열려 있어 같은 네트워크의 다른 기기는 접속할 수 없습니다.
  • API 키는 .env에만 있고 브라우저 화면으로 전달되지 않습니다. 다만 질문과 회의 내용은 선택한 AI 회사의 서버로 전송됩니다. 민감한 개인정보·기밀은 올리지 마세요.
  • CLI 방식은 임시 폴더에서 실행되어 내 파일을 읽지 않도록 했습니다. 폴더 기능은 내가 지정한 폴더만 읽고 그 안의 결과물 폴더에만 새 파일을 씁니다. 다른 웹사이트가 이 프로그램을 몰래 조종하지 못하도록 주소와 출처가 localhost인 요청만 받습니다.

이 프로그램은 개인용 베타입니다. Windows·macOS 실행파일은 제작 환경에서 직접 실행해 보지 못했으니, 문제가 생기면 콘솔 창의 메시지를 그대로 알려 주세요.
