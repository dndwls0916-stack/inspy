🧑‍⚖️ AI 회의실 사용 설명서

컴퓨터를 처음 써 보는 사람도 순서대로만 따라 하면 되도록 썼어요. 모르는 낱말은 맨 아래 낱말 풀이에 있어요.

이게 뭐예요?준비물① 켜기② Claude③ ChatGPT④ Gemini⑤ 첫 회의더 잘 쓰기돈·한도막혔어요낱말 풀이

이게 뭐예요?

질문 하나를 쓰면 여러 AI 친구(Claude, ChatGPT, Gemini)가 회의실에 둘러앉아 서로 의견을 말하고, 서로 반박하고, 마지막에 결론을 정리해서 보여 주는 프로그램이에요.

  • ⚖️ 변호사, 📈 투자자, 💼 CFO 같은 직업을 AI에게 정해 줄 수 있어요. (56가지)
  • 👥 회의 인원은 1명~8명. 6명을 전부 Claude로 할 수도, 반반으로 나눌 수도 있어요.
  • 📎 파일(문서, 엑셀, 파워포인트)을 읽혀서 회의하고, 결과를 워드·엑셀·파워포인트 파일로 저장할 수도 있어요.
이 프로그램이 내 컴퓨터 밖으로 보내는 것 내가 쓴 질문과 붙인 파일 내용은 AI 회사(Anthropic, OpenAI, Google)의 서버로 전송돼요. 비밀번호, 주민번호, 회사 기밀 같은 건 올리지 마세요.

시작하기 전에 준비할 것

준비물왜 필요해요?
💻 Windows 컴퓨터 (10 또는 11), 인터넷프로그램을 켜요.
🟠 Claude 계정 (구독 중인 것)Claude AI를 불러요. 돈이 따로 안 들고 구독 사용량 안에서 써요.
🟢 ChatGPT 계정ChatGPT AI를 불러요. 이것도 구독(또는 무료 계정) 안에서 써요.
🔵 Google 계정 (지메일)Gemini의 무료 열쇠(API 키)를 만들어요.
왜 이렇게 나눠요? (비용 때문이에요) Claude와 ChatGPT는 이미 내는 구독으로 쓰고, Gemini는 무료 열쇠로 써요. 그래서 추가 요금이 거의 안 들어요. 이 프로그램은 이 조합을 "혼합"이라고 불러요. (열쇠가 있는 AI는 열쇠로, 없는 AI는 로그인해 둔 프로그램으로 불러요.)

전체 순서는 이래요. 각 단계는 10분 안팎이에요.

① 프로그램 켜기더블클릭
② Claude 연결한 번만
③ ChatGPT 연결한 번만
④ Gemini 열쇠 넣기한 번만
⑤ 첫 회의!질문 쓰기

②③④는 처음 한 번만 하면 돼요. 다음부터는 ①만 하면 바로 쓸 수 있어요.

① 프로그램 켜기

  1. 압축 풀기. 받은 ai-council-windows.zip 파일 위에서 마우스 오른쪽 버튼 → 모두 압축 풀기 → 압축 풀기를 눌러요. 폴더가 하나 생겨요. (바탕화면에 풀면 찾기 쉬워요.)
    꼭 지켜요압축을 풀지 않고 zip 안에서 바로 켜면 안 돼요. 꼭 풀어서 나온 폴더 안에서 켜세요.
  2. 더블클릭. 폴더 안의 AI-Council.exe 를 마우스 왼쪽 버튼으로 두 번 빠르게 눌러요.
  3. 파란 창이 나오면. "Windows의 PC 보호" 파란 창이 뜰 수 있어요. 고장이 아니에요. 직접 만든 프로그램이라 Windows가 처음 보는 것뿐이에요.
    1. 추가 정보를 눌러요.
    2. 그러면 나타나는 실행 버튼을 눌러요.
  4. 검은 창이 나오고, 잠시 뒤 인터넷 창(브라우저)이 열려요. 이 화면이 나오면 성공이에요. (아래 그림)
    검은 창은 닫지 마세요!검은 창을 닫으면 프로그램이 꺼져요. 작게 줄여(－ 버튼) 두면 돼요. 다 쓰고 끌 때만 닫으세요.
  5. 인터넷 창이 저절로 안 열리면 인터넷 창(크롬 등)을 직접 열고, 맨 위 주소 칸에 localhost:3000 이라고 쓰고 Enter 를 눌러요.
✅ 이렇게 보이면 성공이에요왼쪽에 "AI 회의실" 제목과 참가자 카드들이 보이고, 오른쪽 아래에 질문을 쓰는 칸이 있어요. 아직 AI가 연결되지 않아서 카드에 "설정이 필요합니다" 같은 빨간 글씨가 보일 수 있어요. 괜찮아요. ②③④에서 연결할 거예요.

이 단계에서 프로그램이 같은 폴더에 .env 라는 설정 파일을 저절로 만들어요. ④에서 쓸 거예요.

② Claude 연결하기 (한 번만)

Claude를 부르는 작은 프로그램(claude)을 깔고, 내 Claude 계정으로 로그인해 두는 거예요.

  1. PowerShell 열기. 키보드 왼쪽 아래 윈도우 키(⊞)를 누르고 powershell 이라고 쳐요. Windows PowerShell이 나오면 눌러요. 파란 창이 열려요.
  2. 아래 한 줄을 복사해서 붙여 넣기. 아래 회색 칸을 한 번 클릭하면 전체가 선택돼요 → Ctrl+C 로 복사 → 파란 창을 한 번 클릭하고 마우스 오른쪽 버튼을 누르면 붙여 넣어져요 → Enter. 
    irm https://claude.ai/install.ps1 | iex
    글자가 줄줄 올라가다가 멈추면 끝난 거예요. (1~2분)
  3. PowerShell을 닫고 다시 열어요. (새로 깔린 걸 컴퓨터가 알아보게 하려고요.)
  4. 로그인. 파란 창에 이렇게 쳐요. 
    claude
    인터넷 창이 열리면 내 Claude 계정으로 로그인하고 허락(Authorize)을 눌러요. 파란 창으로 돌아오면 "이 폴더를 믿을까요?" 같은 질문이 나올 수 있어요. Yes(1번)를 고르고 Enter 를 눌러요.
  5. 나가기. 파란 창에 /exit 라고 쓰고 Enter. (안 되면 Ctrl+C 를 두 번 눌러요.)
  6. 잘 됐는지 확인. 
    claude --version
    숫자(예: 2.1.0)가 나오면 성공이에요.
"claude 라는 말은 이름이 인식되지 않습니다"가 나오면 컴퓨터가 방금 깐 프로그램의 위치를 모르는 거예요. 아래 한 줄을 붙여 넣고 Enter → PowerShell을 닫았다가 다시 열고 claude --version 을 다시 해 보세요. 
[Environment]::SetEnvironmentVariable("Path", $env:Path + ";$env:USERPROFILE\.local\bin", "User")
그래도 안 되면 설치가 끝날 때 파란 창에 나온 "PATH"에 관한 안내 글을 읽고 그대로 따라 하세요.

③ ChatGPT 연결하기 (한 번만)

ChatGPT를 부르는 작은 프로그램(codex)을 깔고 로그인해요. 이 프로그램을 깔려면 먼저 Node.js라는 것이 필요해요. (처음 한 번만요.)

  1. Node.js 깔기. 인터넷 창에서 nodejs.org 에 들어가요. LTS라고 적힌 초록색 큰 버튼을 눌러 받아요. 받은 파일을 열고 Next(다음)만 계속 눌러서 끝까지 가요.
  2. PowerShell을 새로 열어요. (②에서 열었던 건 닫고 새로요.)
  3. codex 깔기. 
    npm install -g @openai/codex
    1~3분 걸려요. 글자가 멈추고 다시 입력할 수 있게 되면 끝이에요.
  4. 로그인. 
    codex login
    인터넷 창이 열리면 ChatGPT 계정으로 로그인하고 허락을 눌러요. 파란 창에 Successfully logged in 이 보이면 성공이에요.
    인터넷 창이 안 열리면codex login --device-auth 라고 쳐 보세요. 주소와 코드가 나와요. 그 주소를 인터넷 창에서 열고 코드를 넣으면 돼요. 내가 직접 시작한 로그인의 코드만 넣으세요. 누가 보내 준 코드는 넣지 마세요.
  5. 잘 됐는지 확인. 
    codex --version
codex login status
    버전 숫자가 나오고 Logged in using ChatGPT 라고 나오면 성공이에요.
"이 시스템에서 스크립트를 실행할 수 없으므로 npm.ps1 파일을…" 이라는 빨간 글이 나오면 PowerShell 대신 명령 프롬프트를 쓰면 돼요. 윈도우 키(⊞)를 누르고 cmd 라고 쳐서 명령 프롬프트(검은 창)를 열고, 같은 줄을 다시 입력하세요.

④ Gemini 열쇠 만들어서 넣기 (한 번만, 무료)

Gemini는 열쇠(API 키)를 만들어서 프로그램에게 알려 주는 방식으로 써요. 열쇠는 AIza… 로 시작하는 긴 글자예요.

  1. 열쇠 만들기. 인터넷 창에서 aistudio.google.com/apikey 에 들어가요. Google 계정으로 로그인하고 Create API key(API 키 만들기)를 눌러요. 긴 글자가 나오면 복사 버튼을 눌러요.
    열쇠는 비밀번호예요다른 사람에게 보여 주거나, 카톡·메일로 보내거나, 사진을 찍어 올리지 마세요. 실수로 남에게 보였다면 같은 사이트에서 그 열쇠를 지우고 새로 만드세요.
  2. 설정 파일(.env) 열기. ①에서 프로그램이 만든 폴더(AI-Council.exe가 있는 폴더)에서 .env 파일을 찾아요. 마우스 오른쪽 버튼 → 연결 프로그램 → 메모장 으로 열어요.
    .env 파일이 안 보이면폴더 위쪽 메뉴에서 보기 → 표시 → 숨긴 항목과 파일 확장명에 체크(✔)를 해 보세요. 그래도 없으면 프로그램을 한 번 껐다가 다시 켜 보세요(처음 켤 때 만들어져요).
  3. 한 줄 써 넣기. 메모장 맨 아래에 이렇게 써요. = 뒤에 방금 복사한 열쇠를 붙여 넣어요(Ctrl+V). 따옴표(" ")나 빈칸은 넣지 마세요. 
    GEMINI_API_KEY=여기에붙여넣기
    이미 GEMINI_API_KEY= 로 시작하는 줄이 있으면 그 줄 뒤에 붙여 넣으면 돼요. 앞에 # 이 붙어 있으면 # 을 지워요.
  4. 저장. Ctrl+S 를 누르고 메모장을 닫아요.
  5. 프로그램을 껐다가 다시 켜요. 검은 창을 닫고, ①처럼 AI-Council.exe 를 다시 더블클릭해요. 설정 파일을 고치면 꼭 다시 켜야 해요.
✅ 이렇게 보이면 성공이에요 — "혼합" 검은 창에 기본 실행 방식: MIXED 가 보이고, 인터넷 창 왼쪽 "실행 방식"에서 혼합이 파랗게 켜져 있어요. 참가자 카드(GPT, Gemini, Claude)에 빨간 경고가 없으면 준비 끝이에요! 🎉
Gemini 무료 열쇠에 대해 꼭 알아 두세요
  • 지금 무료 열쇠로는 "3.5 flash-lite"라는 가벼운 모델만 쓸 수 있는 걸로 확인됐어요. 이 프로그램은 모델을 "자동"으로 두면 이 가벼운 모델을 먼저 써서 그냥 돼요. 모델 칸은 건드리지 마세요.
  • 무료라서 1분에 보낼 수 있는 횟수가 적어요. 너무 빨리 많이 부르면 429 라는 글이 나와요. 그러면 1분쯤 기다렸다가 다시 하거나, 참가자 수·토론 횟수를 줄이세요. 한 회의에 Gemini를 여러 자리 앉히면 더 빨리 걸려요.
  • Claude와 ChatGPT의 열쇠(API 키)는 넣지 마세요. 넣으면 구독이 아니라 열쇠(유료 종량제)로 불러서 돈이 따로 나가요. (Gemini 열쇠만 넣는 게 정답이에요.)

⑤ 첫 회의 해 보기

  1. 처음엔 가볍게. 왼쪽 토론 라운드가 "2 (의견 + 반박)" 인지만 확인해요. 참가자는 그대로(GPT, Gemini, Claude)요.
  2. 질문 쓰기. 아래 칸에 이런 질문을 써 봐요. "점심 메뉴를 정하는 가장 공정한 방법은?"
  3. 회의 시작 버튼을 눌러요. (또는 Ctrl+Enter)
  4. 기다려요. 카드가 하나씩 생기며 AI들이 말해요. 한 번에 10~60초 걸릴 수 있어요. 처음엔 1~3분 걸려도 정상이에요. 멈추고 싶으면 중단을 눌러요.
  5. 결론 읽기. 맨 아래 노란 칸이 최종 결론이에요.
번호이게 뭐예요?
1최종안 확인 — 모두가 각자 따로 "찬성/조건부/반대"를 눌러요. 전원이 찬성해야 합의예요. 눈치 보고 맞장구치는 걸 막으려는 장치예요.
2최종 결론 — 결론, 합의된 점, 의견이 갈린 점, 다음에 할 일이 정리돼요.
3💾 결과물로 저장 — 이름과 종류(.md, .docx 워드, .xlsx 엑셀, .pptx 파워포인트 …)를 고르고 저장을 누르면 파일이 만들어져요. (먼저 📁 폴더에서 저장할 폴더를 정해야 해요. 아래에 설명이 있어요.)
4회의록 저장됨 — 회의 전체 기록이 저절로 파일로 저장돼요. 프로그램 폴더 안 "회의록" 폴더에 있어요.
여기까지 했으면 기본은 끝!이제 아래 "더 잘 쓰기"에서 필요한 것만 골라 보세요. 다 읽을 필요는 없어요.

더 잘 쓰기

사무실 화면

화면 위쪽에 사무실이 있고, 참가자들이 자기 책상에 앉아 있어요. 질문을 쓰고 회의 소집을 누르면 모두 회의실로 걸어가서 토론해요. 누가 생각 중인지, 누가 말했는지는 머리 위 표시로 보여요. 토론 내용 전체는 회의록 폴더에 저장되고, 화면에는 질문과 결론만 남아요. 전체 토론 글을 보고 싶으면 "토론 내용 보기" 버튼을 누르세요. 끝나면 모두 책상으로 돌아가요.

회의 중에 끼어들기

회의가 돌아가는 동안에도 글 쓰는 칸에 쓸 수 있어요. 버튼이 "끼어들기"로 바뀌어요. 예를 들어 "이번 분기 예산은 최대 300만원이야"라고 쓰고 보내면, AI들이 다음 라운드부터 그 말을 듣고 이야기하고 최종 결론에도 넣어요. 토론이 충분하다 싶으면 "여기서 결론"을 눌러요. 지금 라운드가 끝나면 거기까지의 토론으로 결론을 정리해요. 한 회의에서 10번까지 끼어들 수 있어요. (이미 말하고 있는 라운드는 끝낸 뒤에 반영돼요.)

엑셀은 필요한 부분만 골라서

첨부 버튼으로 엑셀(.xlsx)을 올리면 창이 열려요. 왼쪽에서 시트를 고르고, 시작 행·끝 행을 정하고, 보낼 열에 체크하세요. 전화번호 같은 열은 체크를 풀면 AI에게 아예 가지 않아요. "행 걸러내기"에 낱말(예: A노선)을 쓰면 그 낱말이 있는 줄만 보내요. 미리보기로 확인한 뒤 첨부하기를 누르세요. 다른 시트도 이어서 고를 수 있어요. 날짜는 숫자(45219)가 아니라 날짜(2023-10-20)로 바뀌어서 가요. 폴더로 읽은 엑셀에도 "시트·행 고르기" 버튼이 있어요.

개인정보 가리기 (기본으로 켜져 있어요)

기사님 전화번호, 주민번호, 이메일, 계좌번호, 차량번호는 AI에게 보내기 전에 [전화1] 같은 이름표로 바뀌어요. 같은 번호는 같은 이름표라서 AI가 "같은 사람"인 건 알 수 있어요. 왼쪽 "개인정보 보호"에서 가릴 이름(기사님 이름 등)을 한 줄에 하나씩 적어 두세요. "지금 질문·첨부로 미리보기"를 누르면 무엇이 가려지는지 먼저 볼 수 있어요. 주소와 목록에 없는 이름은 못 찾으니, 중요한 자료는 미리보기로 꼭 확인하세요.

숫자는 AI가 아니라 프로그램이 계산해요

엑셀 창에서 "숫자 열 합계·평균을 코드로 계산해 함께 첨부"를 켜면, 고른 행 전체의 합계·평균·최소·최대를 프로그램이 계산해 표로 붙여요. "묶어서 합계 낼 열"(예: 캠프, 거래처)을 고르면 묶음별 합계도 나와요. AI는 큰 표의 계산을 틀리기 쉬워서, 계산은 프로그램이 하고 AI는 해석만 하게 한 거예요. 번호·전화·계좌 같은 열은 숫자로 보지 않고 건너뛰어요. 단, 엑셀에 값이 저장되지 않은 수식 칸은 비어 있는 것으로 계산돼요.

처음 실행할 때: 연결 설정

왼쪽 "연결 설정"에서 AI별로 API 키를 붙여 넣고 저장하면 실행파일 옆 .env 파일에 적히고 바로 쓸 수 있어요(다시 실행할 필요 없음). 키가 하나도 없으면 이 칸이 저절로 열려요. 저장한 키는 화면에 다시 나오지 않고, 키 지우기로 지울 수 있어요. 연결 확인을 누르면 아주 짧은 요청을 한 번 보내서 진짜 되는지 확인해요(유료 API는 아주 적은 비용이 들어요). 아래쪽에는 회의록 폴더, 회사 정보 파일, 설정 파일에 저장할 수 있는지가 ✓/✗로 나와요. ✗면 폴더 권한을 확인하거나 다른 위치에서 실행해 보세요.

빠진 칸 미리 알려 주기 (사전 점검)

안건 양식에서 앞쪽 핵심 칸이 비어 있거나 절반이 넘게 비어 있으면, 회의를 시작하기 전에 어떤 칸이 비었는지 알려 주고 그래도 시작할지 물어요. AI 호출은 돈이 드니까, 아는 값은 채우고 시작하는 편이 좋아요. 비운 칸은 "미확인"으로 전달돼요.

사전 부검 (선택)

왼쪽 "사전 부검"을 켜면 결론이 난 뒤에 "이 결정대로 했는데 석 달 뒤 실패했다면, 가장 그럴듯한 이유 3가지"를 표로 덧붙여요. 이유, 미리 볼 수 있는 신호, 지금 할 수 있는 예방이 나와요. AI 호출이 1회 더 들고, 호출 상한이 모자라면 생략돼요. AI의 가정이지 확인된 사실은 아니에요. 회의록에도 저장돼요.

회의 끝 알림

회의가 끝나면 짧은 소리가 나요. 다른 창을 보고 있었다면 탭 제목이 "✅ 회의가 끝났습니다"로 깜박이고, 브라우저 알림을 허락했다면 알림도 떠요. 왼쪽 "회의 끝 알림"으로 끌 수 있어요.

백업·옮기기

왼쪽 "백업·옮기기"에서 백업 내려받기를 누르면 회의록과 회사 정보가 zip 하나로 내려와요. 새 PC에서는 백업 불러오기로 다시 넣어요. 이미 있는 파일은 덮어쓰지 않고, API 키(.env)와 첨부 원본은 들어가지 않아요. (화면 설정은 브라우저에 저장되어 있어 옮겨지지 않아요.)

지난 회의 이어 가기

글 쓰는 칸 위의 "지난 회의" 버튼을 누르면 저장된 회의록을 찾을 수 있어요. 제목이나 결론의 낱말로 검색하고 "이어 가기"를 누르면, 그 회의 결론이 이번 회의의 배경으로 붙어요. 붙은 회의는 칸 위에 나타나고 ×를 누르면 떼요. (회의록은 실행파일 옆 회의록 폴더에 저장돼요.)

1. 직업(역할) 정해 주기 — "변호사 AI", "투자자 AI"

참가자 카드의 "역할 없음" 칸을 눌러 직업을 골라요. 그러면 그 AI가 그 직업의 눈으로 따지고, 꼭 확인할 것을 점검해요. 예) 변호사는 계약서의 위험한 부분을 찾고, 비판자는 일부러 약점을 파고들어요.

직업은 56가지예요: 대표·CFO·CTO·팀장, 펀드매니저·애널리스트·퀀트·리스크 매니저(주식투자팀), 변호사·회계사·의사, 개발자·보안·디자이너, 마케터·영업·고객지원, 인사·노무, 진행자, 비판자 …

⚠️ 알아 두세요: 직업은 AI에게 "이 직업의 눈으로 따져 봐"라고 시키는 것이지, 없던 지식이 생기는 건 아니에요. 아는 만큼만 말해요. 법·세금·의료·투자 말은 참고용이고, 중요한 결정은 진짜 전문가에게 꼭 물어보세요.
더 똑똑하게 만드는 법: 회의 전에 진짜 자료(계약서, 회사 규정, 재무 엑셀, 보고서)를 📎 첨부하거나 폴더로 알려 주세요. 그러면 참가자들이 그 자료를 근거로 말해요.

2. 팀 한 번에 만들기 + 어떤 AI로 채울지 정하기

직업을 하나씩 정하기 귀찮을 때 쓰세요. 팀 구성에서 "주식투자팀(종목 투자 결정)", "임원회의", "법률·계약 검토" 같은 28가지 팀 중 하나를 고르면, 멤버와 직업이 한 번에 만들어져요.

② AI 배정이 "그 멤버들을 누구로 채울까"예요:

고르는 것결과 (멤버가 6명일 때)
골고루 돌아가며GPT, Gemini, Claude, GPT, Gemini, Claude
전부 Claude (또는 전부 GPT, 전부 Gemini)6명 모두 Claude (화면에는 Claude 1, Claude 2 … 로 보여요)
반반 (두 AI 선택) → 예: GPT + Claude앞 3명은 GPT, 뒤 3명은 Claude
  • 순서가 중요해요: ② AI 배정을 먼저 고르고, 그다음 ① 팀 구성을 고르세요.
  • 팀을 만든 뒤에 AI만 바꾸고 싶으면 ② AI 배정을 다시 고르고 "지금 참가자에 AI 다시 배정" 버튼을 눌러요. 직업은 그대로예요.
  • 한 명(한 자리)만 바꾸고 싶으면 그 카드 위쪽의 AI 이름 칸(GPT, Claude …)을 눌러 바꿔요.
  • 카드의 × 는 빼기, 맨 아래 "+ 참가자 추가" 는 한 명 더하기예요(최대 8명).

3. 토론 횟수 정하기 (라운드)

고르는 것뜻
1각자 의견만 말해요. 가장 빠르고 싸요.
2 (처음 설정)의견을 말하고, 서로 반박해요.
3한 번 더 깊게 토론해요.
합의까지 (최대 4 / 6라운드)다 같이 같은 결론이 될 때까지 계속해요. 그래도 안 되면 최대 횟수에서 멈춰요.
결론 날 때까지 (제한 없음)횟수 제한 없이 합의될 때까지 계속해요. 호출 상한(아래) 때문에 무한히 돌지는 않아요.

4. 파일 읽히기와 결과 저장하기

  • 📎 첨부: 질문 칸 위의 버튼을 누르거나, 파일을 화면에 끌어다 놓아요. 글(.txt), 표(.csv), PDF, 워드(.docx) 등을 읽어요. 모든 AI가 같은 자료를 읽어요.
  • 📁 폴더: 폴더 주소를 붙여 넣고 읽기를 누르면 폴더 안의 문서(워드, 엑셀, 파워포인트 포함)를 읽어서 목록으로 보여 줘요. 보낼 파일에 ✔ 하고 선택한 파일을 첨부를 눌러요.
    폴더 주소 알아내기: 폴더를 연 뒤 위쪽 주소 칸을 클릭하면 C:\Users\… 같은 글이 나와요. 그걸 복사해서 붙여 넣어요.
  • 💾 결과물로 저장: 회의가 끝나면 결론 아래에 나와요. 파일 이름과 종류(워드·엑셀·파워포인트 등)를 고르고 저장하면, 읽어 온 폴더 안 "결과물" 폴더에 새 파일로 만들어져요. 기존 파일은 절대 덮어쓰지 않아요.
  • 안 읽히는 것: 사진, 한글(.hwp), 옛날 형식(.xls .ppt .doc), 글자 없는 스캔 PDF.

5. 삼국지 모드 (재미 모드)

왼쪽 위 삼국지 모드에 체크하면 유비·관우·장비가 병풍 앞 원탁에 앉고, 마지막에 제갈량이 한마디 해요. 기본 3명(GPT, Gemini, Claude)이 한 명씩일 때만 쓸 수 있어요. 같은 AI를 여러 자리에 앉히면 저절로 꺼져요.

6. 다른 AI도 쓰고 싶어요 (Grok, DeepSeek, Llama …)

꼭 안 해도 돼요. 원하면 .env 파일에 열쇠를 한 줄 더 쓰면 "+ 참가자 추가" 목록의 "그 밖의 AI"에 나와요. 이 AI들은 열쇠(유료일 수 있어요)가 필요해요.

AI.env 에 쓰는 줄특징
GrokXAI_API_KEY=열쇠
DeepSeekDEEPSEEK_API_KEY=열쇠싼 편
PerplexityPERPLEXITY_API_KEY=열쇠인터넷 검색을 해서 답해요(최신 정보)
Mistral / Groq / OpenRouterMISTRAL_API_KEY= / GROQ_API_KEY= / OPENROUTER_API_KEY=OpenRouter는 열쇠 하나로 수백 개 모델
Ollama (내 컴퓨터에서, 무료)OLLAMA_MODEL=llama3.1미리 Ollama를 깔고 모델을 받아 둬야 해요. 내용이 밖으로 안 나가요.

돈과 한도 걱정될 때

  • 시작 버튼 위에 "예상 AI 호출 7회"처럼 이번 회의가 AI를 몇 번 부를지 미리 보여 줘요. 사람 수가 많고 토론이 길수록 늘어요. 숫자가 크면 라운드나 사람 수를 줄이세요.
  • AI 호출 상한(왼쪽 아래, 처음 120회): 이 횟수에 닿으면 자동으로 멈추고 그때까지의 내용으로 결론을 정리해요. 걱정되면 30회나 60회로 낮춰요.
  • Claude·ChatGPT 구독은 사용량 한도가 있어요. 호출이 많으면 한도가 빨리 줄어요. 처음엔 라운드 1~2, 3명으로 시험하세요.
  • 첨부 파일은 부를 때마다 다시 들어가요. 큰 파일은 호출 수가 많을수록 부담이 커져요. 필요한 부분만 올리세요.
  • 회의는 동시에 2개까지만 돌아가요.

막혔어요! (문제 해결)

먼저 빨간 카드에 적힌 글을 읽어 보세요. 아래에서 비슷한 걸 눌러 보면 해결 방법이 나와요.

zip 파일이 "올바르지 않다"고 나와요

받는 도중에 파일이 깨진 거예요. 다시 받아 보세요. 받은 파일 크기가 보내 준 것과 같은지(약 33MB) 확인하세요. 그래도 안 되면 알려 주세요.

"Windows의 PC 보호" 파란 창이 떠요

추가 정보 → 실행을 누르세요. 직접 만든 프로그램에 Windows가 처음 보여 주는 정상 안내예요.

검은 창은 떴는데 인터넷 창이 안 열려요

인터넷 창(크롬 등)을 직접 열고 주소 칸에 localhost:3000 을 쓰고 Enter.

"포트 3000이 이미 사용 중입니다"

프로그램이 이미 켜져 있는 거예요. 이미 열린 검은 창을 모두 닫고 다시 켜세요. 그래도 같으면 .env 맨 아래에 PORT=3001 이라고 쓰고 저장한 뒤 다시 켜고, 주소는 localhost:3001 로 들어가세요.

카드에 "설정이 필요합니다" 빨간 글씨가 있어요

그 AI가 아직 연결되지 않았다는 뜻이에요. Claude는 ②, ChatGPT는 ③, Gemini는 ④를 다시 확인하세요. 하고 나서 프로그램을 껐다가 다시 켜세요. (연결된 AI만으로도 회의는 돼요. 연결 안 된 자리는 건너뛰어요.)

"claude 라는 말은 이름이 인식되지 않습니다" / "codex …"

설치는 됐는데 컴퓨터가 위치를 모르는 거예요. ② 아래 노란 칸의 방법을 해 보고, PowerShell과 이 프로그램을 모두 껐다가 다시 켜세요.

빨간 글: "종료 코드 1 …" 또는 시간 초과 (Claude, ChatGPT 카드)

대부분 이 중 하나예요.

  1. 로그인이 풀렸어요 → ② 또는 ③의 로그인 단계를 다시 해요.
  2. 구독 사용량을 다 썼어요 → 시간이 지난 뒤(몇 시간 뒤나 다음 날) 다시 해요.
  3. 처음 한 번 나오는 질문에서 멈췄어요 → 파란 창에서 claude 또는 codex 를 직접 켜서 질문에 답한 뒤 나와요.
  4. 인터넷이 끊겼어요.

파란 창에서 claude -p "안녕" 이 직접 되는지 보면 원인을 나눌 수 있어요.

Gemini 카드에 "429" 또는 "quota" 또는 "limit: 0"

"429"는 "너무 빨리 많이 불렀어요"라는 뜻이에요. 1분쯤 기다렸다가 다시 하세요. 참가자를 줄이거나 라운드를 줄이면 덜 걸려요.

"limit: 0" 은 "그 모델은 무료로 못 써요"라는 뜻이에요. 모델 칸을 "자동"으로 바꾸세요. 이 프로그램이 무료로 되는 가벼운 모델(flash-lite)을 먼저 써 봐요.

Gemini 카드에 "404" 또는 "no longer available" 또는 "model not found"

고른 모델이 이 계정에서는 못 쓰는 거예요. 모델 칸을 "자동"으로 바꾸거나, 목록에서 flash-lite가 들어간 모델을 고르세요. 그리고 .env 에 GEMINI_MODEL= 줄이 있으면 그 줄을 지우세요.

카드에 "401" 또는 "invalid api key"

열쇠가 틀렸거나 지워진 거예요. ④처럼 새 열쇠를 만들어 .env 를 고치고 다시 켜세요. 앞뒤에 빈칸이나 따옴표가 없는지 보세요.

"이미 회의가 2개 진행 중입니다"

회의가 아직 돌고 있어요. 끝나길 기다리거나 중단을 누르세요.

회의가 너무 오래 걸려요

AI를 부르는 횟수가 많아서예요. 라운드를 1~2로, 참가자를 3명으로 줄여 보세요. 시작 버튼 위 "예상 AI 호출"을 보세요. Claude·ChatGPT는 한 번 부를 때 10~60초 걸려요.

화면이 이상해요 / 예전 모습이에요

인터넷 창에서 Ctrl+F5 를 눌러요.

회의 기록은 어디 있어요?

프로그램 폴더(AI-Council.exe가 있는 곳) 안의 회의록 폴더에 날짜_시각_질문.md 파일이 있어요. 메모장으로 열 수 있어요. 기록이 남는 게 싫으면 왼쪽 아래 "회의록 자동 저장" 체크를 풀어요.

백신 프로그램이 막아요

직접 만든 프로그램이라 백신이 의심할 수 있어요. 받은 곳을 믿을 수 있을 때만 예외로 허용하세요.

파일 첨부가 안 돼요

지원 형식(글, 표, PDF, 워드)인지 확인하세요. 글자 없는 스캔 PDF와 사진은 못 읽어요. 용량이 가득 차면 필요 없는 첨부를 × 로 지우세요. 엑셀·파워포인트는 📁 폴더로 읽어요.

그래도 안 되면: 검은 창에 적힌 글과 빨간 카드의 글을 사진으로 찍어(열쇠가 보이지 않게 가리고!) 알려 주세요. 가장 빨리 원인을 찾을 수 있어요.

어른용 메모 (Mac · Linux · 개발자)

  • Linux: 실행 권한을 주고 실행해요. chmod +x ai-council-linux-x64 && ./ai-council-linux-x64
  • macOS: 서명 문제로 macOS에서 직접 빌드해야 해요(GitHub Actions의 Build executables 사용). 막히면 우클릭 → 열기.
  • 소스로 실행(Node.js 18+): cp .env.example .env 후 npm start → http://localhost:3000. 시험은 npm test, 연습용 가짜 답변은 npm run demo.
  • 설정 항목은 .env.example 참고(MAX_CALLS, NO_MINUTES, MINUTES_DIR, PORT, 다른 AI 열쇠 등). 자세한 구조는 README.md.
  • 이 프로그램은 127.0.0.1(내 컴퓨터)에서만 열려요. 질문과 파일 내용은 선택한 AI 회사로 전송돼요. 회의록에는 질문과 AI 답변이 일반 글자 파일로 남아요.
  • Windows 실행파일과 실제 AI 연결은 제작 환경에서 직접 확인하지 못했어요. 문제가 생기면 검은 창의 글을 알려 주세요.
